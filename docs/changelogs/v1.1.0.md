# v1.1.0 — Remove Manual Approval + Fix Workbook Sync

**Date:** July 26, 2026

## Changes

### 1. Removed manual approval workflow ("review" → "approved" → "rejected")

Batch building episodes now auto-advance through the pipeline:
- Completed builds → "complete" or "scheduled" status automatically
- Removed all approve/reject UI from every dashboard page
- Removed approval API routes (`POST /episodes/:id/approve`, `POST /episodes/:id/reject`)

**DB schema change:** `episode_status` enum reduced from 9 to 6 values:
- Removed: `review`, `approved`, `rejected`
- Kept: `draft`, `scripted`, `complete`, `scheduled`, `published`, `building`

**Data migration ran automatically:**
- `approved` → `complete` (17 episodes)
- No `review` or `rejected` episodes were affected

### 2. Preview Queue repurposed as read-only log
- No more Approve/Reject buttons
- Pipeline auto-schedule info panel explains the new workflow
- Manual "Mark Complete" button available as fallback

### 3. Dashboard status filters updated
- Removed: review, approved, rejected
- Added: scripted, building (for completeness)
- "Approved" stat card replaced with "Complete" card

### 4. Seed script updated
- Workbook status mapper maps "approved" → "complete" instead of "approved"
- Batch 51–65 now seeds as "complete" instead of "approved"
- Test episodes (998, 999) seed as "complete"
- Removed hardcoded `markApproved` logic branch

### 5. Pipeline status header updated
- "Apr" pill → "Cmp" (Complete)
- "NEED BUILD" → "READY TO PUBLISH" when episodes are in complete state

### 6. API & codegen regenerated
- OpenAPI spec, zod schemas, and react-query hooks regenerated
- Removed `useApproveEpisode`, `useRejectEpisode` hooks
- Updated all status enums across generated types
